# 故障排除：遇到问题先查这里

按"你看到的症状"查找。每条都有【为什么】和【怎么办】。

---

## 症状：双击启动脚本没反应 / 一闪而过

**为什么**：Windows 对陌生脚本默认警惕，或者被杀毒软件直接拦截了。

**怎么办**：
1. 右键脚本 →「属性」→ 如果底部有"解除锁定"，勾上，确定，再双击
2. 还不行：把 U 盘根目录加入杀毒软件白名单
   - 360 / 腾讯管家：主界面 → 设置 → 信任区/白名单 → 添加 U 盘根目录（如 `E:\`）
   - Windows Defender：设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项 → 添加文件夹 → 选 U 盘根目录

## 症状：提示"端口 18789 被占用"

**为什么**：这台电脑上已经有一个 OpenClaw 在跑（可能上次没关干净，或装了别的版本）。

**怎么办**：任务栏/任务管理器里找到 OpenClawGateway 或 node 相关的黑色窗口，关掉再启动。如果找不到，直接重启电脑最省事。

## 症状：蓝色窗口"Windows 已保护你的电脑"

**为什么**：脚本没有花钱购买微软开发者签名，Windows 不认识它就拦截。这是正常的，不是病毒。

**怎么办**：点「更多信息」→「仍要运行」。

## 症状：浏览器没自动打开 / 打开后要求输 Gateway Token

**为什么**：一般双击启动脚本能自动登录；手动打开浏览器访问就会要口令。

**怎么办**：口令就是启动时向导里你自己设的那个。忘了的话：记事本打开 `U盘\data\.openclaw\openclaw.json`，找 `"token"` 那一行，引号里的内容就是。

## 症状：模型回复"Context overflow: prompt too large"

**为什么**：在当前这个很长的会话里切到了离线助手，会话历史超出了它的接待预算。

**怎么办**：在聊天框输入 `/new` 开新会话再切离线助手。（根因已修复，新装的不应有此问题；老 U 盘可把配置里 offline-assistant 的 contextWindow 改成 131072。）

## 症状：断网后没有自动切到离线助手

**排查顺序**：
1. 是**新对话**还是旧对话？断网接管只会在新对话或请求失败时触发，旧对话里一直用云端模型的话不会切
2. 离线助手文件齐了吗？检查 `U盘\offline-assistant\` 里有没有 `offline_assistant_fp32.onnx` 和 `model` 文件夹
3. 依赖装了吗？在 `offline-assistant` 文件夹里 Shift+右键开终端，执行 `U盘盘符:\runtime\node\npm.cmd install --omit=dev`
4. 还不行：把启动时黑色窗口的内容截图，去仓库提 issue

## 症状：网络恢复了，怎么切回云端模型

**为什么**：这是已知边界——OpenClaw 的兜底机制"顶班不交还"。

**怎么办**：聊天框输入 `/model`，选回你的云端模型（如 DeepSeek）。自动切回功能在 roadmap 里，欢迎共建。

## 症状：提示"立即更新"的粉色横幅

**为什么**：OpenClaw 检测到新版本。便携版靠锁定版本保持稳定，更新会让 U 盘版配置失效。

**怎么办**：点横幅右边的 **✕ 关掉，永远不要点"立即更新"**。

## 症状：提示某个 .dll 或 node.exe 无法运行

**为什么**：杀毒软件误杀或系统太旧。

**怎么办**：先把 U 盘根目录加白名单，然后从压缩包重新解压对应文件；系统需要 Win10 1809 以上。

## 症状：一切都好慢

**为什么**：第一次启动、第一次调用离线助手都要从 U 盘读几百 MB 进内存，USB 速度是瓶颈。

**怎么办**：等。第一次约 1~2 分钟，之后都在内存里，就快了（离线助手约 1 秒一题）。如果每次都慢，试试换个蓝色的 USB 3.0 口，别用机箱前置老接口。
